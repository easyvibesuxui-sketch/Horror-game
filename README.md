# Waves of Hell (ჯოჯოხეთის ტალღები)

თამაშის ენა — ინგლისური.

პირველი პირის (FPS) ჰორორ შუტერი ბნელ კოსმოსურ სადგურზე, Half-Life-ისა და CS-ის სტილში — ეკრანზე მხოლოდ შენი ხელები და იარაღი ჩანს. შავ ძაღლთან ერთად იცავ სადგურს დემონების დაუსრულებელი ტალღებისგან.

**ითამაშე ბრაუზერში:** https://easyvibesuxui-sketch.github.io/Horror-game/

## გაშვება

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # სტატიკური ვერსია dist/ საქაღალდეში (ნებისმიერ ჰოსტინგზე აიტვირთება)
```

## თამაშის წესები

- **ერთი ლეველი, დაუსრულებელი ტალღები.** ტალღებს შორის 20 წამიანი შესვენებაა (**N** — შემდეგი ტალღის ადრე დაწყება).
- **დემონები**
  - **Easy** — ჰაგი ვაგი, მედდა (Nurse) — ჩვეულებრივი.
  - **Fast** — დემონი ქრომი, წითელი პატარა ჰაგი — სწრაფი, მაგრამ სუსტი.
  - **Brute** — ყასაბი (Butcher), სირენა (Siren Head) — ძლიერი და ნელი. ყოველ მე-5 ტალღაზე დამატებითი ბრუტები მოდიან.
  - თავში მოხვედრა ×1.8 ზიანს აყენებს.
- **ქოინები:** ყოველი მოკლული დემონი = ქოინი (Easy 10, Fast 15, Brute 45) + ბონუსი ყოველი გავლილი ტალღისთვის.
- **მაღაზიის 3 წერტილი** სხვადასხვა ოთახში:
  1. **იარაღის საწყობი** (მარცხენა ოთახი) — 30 იარაღი: პისტოლეტები, პისტოლეტ-ავტომატები, საფანტიანი თოფები, ავტომატები, ტყვიამფრქვევები, სნაიპერული შაშხანები და სპეციალური იარაღი (ცეცხლსასროლი, RPG, ტესლა, ლაზერი, მინიგანი, რელსური ქვემეხი). ერთდროულად 3 იარაღს ატარებ.
  2. **ბრონი და ბომბები** (ზედა ოთახი) — მსუბუქი, მძიმე და ჯაგერნაუტის ბრონი, ყუმბარები, ნაღმები.
  3. **გამაცოცხლებლები და ბუსტერები** (მარჯვენა ოთახი) — 1 გამაცოცხლებელი, სამედიცინო ნაკრები, ორმაგი ზიანი, სწრაფი სროლა, სისწრაფე, რეგენერაცია, დამხმარის მკურნალობა და გაძლიერება.
- **დაცემა:** როცა სიცოცხლე გითავდება, იატაკზე ეცემი პისტოლეტით ხელში. თუ 10 წამს გაუძლებ, ფეხზე დგები; თუ მანამდე მოგკლავენ — კვდები. თუ **გამაცოცხლებელი** გაქვს, ის ფეხზე წამოგაყენებს და დემონებს აფეთქებით უკუაგდებს.
- **დამხმარე (შავი ძაღლი):** ხმლებით ებრძვის დემონებს შენ გვერდით. როცა დემონები დასცემენ, იატაკზე რჩება — მიდი მასთან და დააჭირე და გააჩერე **E**, რომ გააცოცხლო. შეგიძლია რამდენჯერაც გინდა, იმდენჯერ გააცოცხლო.

## მექანიკები

- **ტყვიები:** ყველა იარაღს აქვს მჭიდი და სათადარიგო ტყვიები (საწყისი M9 — ულიმიტო). ტყვიებს იარაღის საწყობში ყიდულობ, ან დემონებიდან ჩამოვარდნილი „მაქსიმალური ტყვიებით“ ივსებ.
- **სიზუსტე:** მარჯვენა ღილაკით უმიზნებ (ზუმი და ზუსტი სროლა, სნაიპერზე ლინზა). სიარულისას და გაუჩერებლად სროლისას ტყვიები იფანტება — სამიზნე ნიშანი ამას აჩვენებს.
- **დანა (V):** ყოველთვის გაქვს; დანით მოკვლას +10 ქოინი მოაქვს.
- **სირბილი (Shift):** ენერგიას ხარჯავს; სირბილისას ვერ ისვრი.
- **სიცოცხლე:** 5 წამი თუ არ დაგარტყეს, ნელ-ნელა ბრუნდება ნახევრამდე; შესვენებისას — სრულად.
- **დემონები:** Fast დემონები ხტებიან, Brute-ები ღრიალებენ და შემდეგ გარბიან შენკენ (გვერდზე გადადგი!), დარტყმის მერე კი დაღლილები არიან. ძლიერი დარტყმა დემონს აბარბაცებს. თავში მოკვლა ×1.5 ქოინი.
- **ბონუსები (ჩამოვარდნილი):** მაქსიმალური ტყვიები, ერთი დარტყმით კვლა (15წ), ორმაგი ქოინები (20წ), ბირთვული აფეთქება.
- **განსაკუთრებული ტალღები:** ყოველ მე-5 — ბრუტები; 3, 8, 13... — სწრაფი დემონების შემოსევა; მე-4-დან ზოგჯერ შუქი ქრება და მხოლოდ ფანარი გრჩება.
- ხმები მიმართულებიანია — ყურსასმენებით გაიგებ, საიდან მოდიან.

- **ტალღის დასრულების ბონუს კრედიტები:** ყოველი ტალღის ბოლოს ჩნდება პანელი: ტალღის ბონუსი, მოკლული დემონები, თავში მოხვედრები, დანით მოკვლები, „ხელშეუხებელი“ (ზიანი არ მიგიღია), სისწრაფის ბონუსი და ბონუსი, თუ შავი ძაღლი არ დაცემულა.
- **პაუზა (Esc / P):** გაგრძელება, თავიდან დაწყება, მაუსის მგრძნობელობა და ყველა კონტროლი.

## ტექნიკური დეტალები

- Three.js + Vite. ყველა ხმა WebAudio-თი სინთეზირდება, აუდიო ფაილები არ სჭირდება.
- მოდელები ოპტიმიზებულია `gltf-transform`-ით (ტექსტურები 1024px WebP, მეშები გამარტივებული და meshopt-ით შეკუმშული): ~88 MB → ~4 MB.
- ქრომისა და შავი ძაღლის მოდელებს ანიმაციები არ ჰქონდათ: სიარული, დარტყმა და დაცემა ძვლებზე პროცედურულად ანიმირდება (`src/rig.js`). ხელები და იარაღი ცალკე სცენაში იხატება (`src/viewmodel.js`), რომ კედლებში არ შევიდეს.
- მტრები გზას პოულობენ ნავიგაციის ბადით, რომელიც ლეველის რეიკასტინგით იგება (`src/nav.js`).
- ბალანსი: იარაღები, დემონები, მაღაზია და ტალღები — `src/config.js`.
