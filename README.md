# ჯოჯოხეთის ტალღები

ჰორორ ტალღების შუტერი ბნელ კოსმოსურ სადგურზე — ზემოდან დამკვირვებლის (spectator) კამერით. დამხმარესთან ერთად იცავ სადგურს დემონების დაუსრულებელი ტალღებისგან.

## გაშვება

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # სტატიკური ვერსია dist/ საქაღალდეში (ნებისმიერ ჰოსტინგზე აიტვირთება)
```

## თამაშის წესები

- **ერთი ლეველი, დაუსრულებელი ტალღები.** ტალღებს შორის 20 წამიანი შესვენებაა (**N** — შემდეგი ტალღის ადრე დაწყება).
- **დემონები**
  - **Easy** (Huggy) — ჩვეულებრივი.
  - **Fast** (წითელი, პატარა Huggy) — სწრაფი, მაგრამ სუსტი.
  - **Brute** (Butcher) — ძლიერი და ნელი. ყოველ მე-5 ტალღაზე დამატებითი ბრუტები მოდიან.
- **ქოინები:** ყოველი მოკლული დემონი = ქოინი (Easy 10, Fast 15, Brute 45) + ბონუსი ყოველი გავლილი ტალღისთვის.
- **მაღაზიის 3 წერტილი** სხვადასხვა ოთახში:
  1. **იარაღის საწყობი** (მარცხენა ოთახი) — 30 იარაღი: პისტოლეტები, პისტოლეტ-ავტომატები, საფანტიანი თოფები, ავტომატები, ტყვიამფრქვევები, სნაიპერული შაშხანები და სპეციალური იარაღი (ცეცხლსასროლი, RPG, ტესლა, ლაზერი, მინიგანი, რელსური ქვემეხი). ერთდროულად 3 იარაღს ატარებ.
  2. **ბრონი და ბომბები** (ზედა ოთახი) — მსუბუქი, მძიმე და ჯაგერნაუტის ბრონი, ყუმბარები, ნაღმები.
  3. **გამაცოცხლებლები და ბუსტერები** (მარჯვენა ოთახი) — 1 გამაცოცხლებელი, სამედიცინო ნაკრები, ორმაგი ზიანი, სწრაფი სროლა, სისწრაფე, რეგენერაცია, დამხმარის მკურნალობა და გაძლიერება.
- **დაცემა:** როცა სიცოცხლე გითავდება, იატაკზე ეცემი პისტოლეტით ხელში. თუ 10 წამს გაუძლებ, ფეხზე დგები; თუ მანამდე მოგკლავენ — კვდები. თუ **გამაცოცხლებელი** გაქვს, ის ფეხზე წამოგაყენებს და დემონებს აფეთქებით უკუაგდებს.
- **დამხმარე (ქრომი):** შენთან ერთად იბრძვის. როცა დემონები დასცემენ, იატაკზე რჩება — მიდი მასთან და დააჭირე და გააჩერე **E**, რომ გააცოცხლო. შეგიძლია რამდენჯერაც გინდა, იმდენჯერ გააცოცხლო.

## ტექნიკური დეტალები

- Three.js + Vite. ყველა ხმა WebAudio-თი სინთეზირდება, აუდიო ფაილები არ სჭირდება.
- მოდელები ოპტიმიზებულია `gltf-transform`-ით (ტექსტურები 1024px WebP, მეშები გამარტივებული და meshopt-ით შეკუმშული): ~88 MB → ~4 MB.
- ქრომის მოდელს არც ტანსაცმელი ჰქონდა და არც ანიმაციები: ტაქტიკური კოსტიუმი შეიდერით იხატება, სიარული, დამიზნება და დაცემა კი ძვლებზე პროცედურულად ანიმირდება (`src/rig.js`).
- მტრები გზას პოულობენ ნავიგაციის ბადით, რომელიც ლეველის რეიკასტინგით იგება (`src/nav.js`).
- ბალანსი: იარაღები, დემონები, მაღაზია და ტალღები — `src/config.js`.
